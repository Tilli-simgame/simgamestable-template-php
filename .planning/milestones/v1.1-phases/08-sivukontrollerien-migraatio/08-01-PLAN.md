<objective>
Migrate 3 static-title public controllers (`index.php`, `hevoset.php`, `kasvatus.php`) to data-only controllers that delegate 100% of HTML rendering to the active theme via `require resolveThemePath('pages/X.php')`. Implements THEME-08 for these 3 of the 5 base pages.

This plan applies both theme-integration mechanisms per **D-01** (retain both, do not consolidate):
- **Malli A** (this phase's core): controller fetches data, then delegates to `resolveThemePath('pages/X.php')`.
- **Malli B** (root-override hook, standardized to the canonical `resolveThemePath()` form per **D-02**): if a non-default theme ships a root-level file of the same name, the whole controller short-circuits into it. Rationale is symmetry/future-proofing per **D-03** — the default theme always uses Malli A.

Old inline HTML (header require + raw HTML body + footer require) is deleted entirely per **D-04** (no dead code). Redundant presentation helpers already owned by the templates (`$genderFi`, `$page_title` for static-title pages) are removed per **D-05**.

Purpose: Decouple controllers from markup so a DB-level theme switch changes appearance with zero controller edits (Success Criteria #3).
Output: 3 migrated controllers; no new persistent symbols.
</objective>
