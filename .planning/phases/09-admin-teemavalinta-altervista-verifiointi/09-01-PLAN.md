<objective>
Deliver Phase 9's only new code artifact — an `.htaccess` that blocks direct HTTP access to the default theme's page templates (THEME-12 folder-protection portion, D-03/D-04) — and formally verify (read-only, no modification per D-05) that the pre-existing `public/admin/settings.php` already satisfies THEME-10 (theme listing) and THEME-11 (theme selection with allowlist + CSRF).

Purpose: Theme page templates (`themes/default/pages/*.php`) expect controller-set variables. A direct HTTP request to them executes the template out of context, emitting PHP notices/warnings that disclose file paths and code structure. An `.htaccess` deny closes that disclosure surface. THEME-10/THEME-11 need no new code — this plan proves the existing implementation meets them so the requirements can be marked complete honestly.

Output: `public/themes/default/pages/.htaccess`; a passing verification of `settings.php` requirement coverage.
